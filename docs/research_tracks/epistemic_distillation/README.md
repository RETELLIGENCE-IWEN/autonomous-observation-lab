# Epistemic Distillation

## Core idea

Transfer not only actions but also belief, uncertainty, future visibility, and observation intent from a privileged teacher to a deployable agent with limited observations.

## Primary research question

> Can a partially observed student internalize how a privileged teacher knows what to look at without inheriting false certainty about information it cannot observe?
