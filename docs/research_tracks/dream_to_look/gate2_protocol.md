# Gate 2 Protocol: Learned Belief and World Models

## Objective

Gate 2 asks whether learned recurrent states preserve and predict the information needed for autonomous observation. It compares a deterministic recurrent baseline, a monolithic RSSM, and an object-centric RSSM under the same trajectories, observable inputs, target heads, optimization budget, and evaluation seeds.

Gate 2 does not yet train the final observation policy.

## Models

| Model | Information state | Purpose |
|---|---|---|
| Deterministic recurrent | one GRU hidden state | Memory baseline |
| Monolithic RSSM | global deterministic state plus one stochastic latent | Test stochastic latent dynamics |
| Object-centric RSSM | per-handle deterministic/stochastic states plus global pooling | Test entity factorization and persistence |

## Dataset

Trajectories are generated by a policy mixture:

- random valid look;
- fixed scan;
- entropy-greedy;
- decision-aware VoI.

Every trajectory records only deployable model inputs:

- detection feature set;
- payload/budget state;
- previous action;
- padding and validity masks.

Privileged simulator state is stored only as supervised target and evaluation metadata:

- per-object signature and motion;
- target predicate;
- position and visibility;
- true object identity for association diagnostics.

Privileged values never enter the encoder or recurrent transition.

## Canonical tensor interface

For batch size \(B\), sequence length \(T\), and maximum objects \(K\):

| Tensor | Shape | Meaning |
|---|---|---|
| detections | \(B\times T\times K\times F\) | padded object-feature observations |
| detection_mask | \(B\times T\times K\) | valid detection slots |
| actions | \(B\times T\times A\) | previous action encoding |
| object_targets | \(B\times T\times K\times Y\) | privileged training/evaluation targets |
| target_mask | \(B\times T\times K\) | valid physical objects |
| visible_target | \(B\times T\times K\) | true current visibility |

Stable-handle training is the initial distribution. Handle corruption is a held-out binding stress test, not mixed silently into the first fit.

## Shared prediction heads

All models predict:

- target predicate logit per object;
- signature-bit logits;
- motion-class logit;
- position mean;
- visibility/detection logit;
- next-step evidence quality;

The deterministic model predicts from its recurrent state. RSSMs predict from deterministic and sampled stochastic state.

## Loss

\[
\mathcal L =
\lambda_q\mathcal L_{\text{target}}
+\lambda_c\mathcal L_{\text{signature}}
+\lambda_m\mathcal L_{\text{motion}}
+\lambda_p\mathcal L_{\text{position}}
+\lambda_v\mathcal L_{\text{visibility}}
+\lambda_e\mathcal L_{\text{evidence}}
+\beta\mathcal L_{\text{KL}}.
\]

The KL term is zero for the deterministic model. RSSM KL uses free-nats/free-bits protection and reports prior and posterior losses separately where implemented.

## Evaluation modes

### Filtering

Process the real observation at every step. This tests representation and belief update.

### Open-loop prior rollout

Infer a posterior from an initial prefix, then remove future observations and roll the model prior forward under recorded actions. This tests imagination rather than reconstruction.

### Occlusion persistence

Evaluate target identity and position during the configured occlusion interval.

### Reacquisition correction

Measure how quickly predictions recover after evidence returns.

### Association-corruption stress

Evaluate without retraining under handle reset, switch, and collision. This is expected to expose the limits of handle-indexed memory and determine whether object-centric binding adds value.

## Primary metrics

- target-predicate BCE, accuracy, AUROC, and Brier score;
- signature and motion accuracy;
- position RMSE;
- visibility BCE and calibration;
- open-loop degradation versus horizon;
- occlusion identity retention;
- reacquisition recovery time;
- performance change under handle corruption.

## Capacity control

Report trainable parameter counts. The monolithic and object-centric RSSMs should be compared both:

1. at similar total parameter count;
2. at a common per-object latent width.

If conclusions change between these controls, report both rather than selecting the favorable comparison.

## Acceptance gates

1. Dataset replay and tensorization are deterministic.
2. The deterministic baseline beats a latest-frame predictor during occlusion.
3. RSSM prior rollout remains useful beyond the observation prefix.
4. Object-centric factorization improves at least one entity-level generalization axis without materially degrading in-distribution filtering.
5. Every claimed advantage survives a fixed unseen seed block and a parameter-count audit.
