# Hypothesis-Driven Active Observation

## Core idea

The observation agent should select evidence that best distinguishes or falsifies competing explanations of the current situation, rather than merely following the most likely target state.

## Primary research question

> Can a mission-weighted belief-space policy resolve decision-relevant hypotheses more efficiently and reliably than tracking-, confidence-, or generic information-gain policies?
