# Research Documentation

This directory organizes the conceptual and research-facing documentation for the Autonomous Observation Lab.

## Structure

- [`vision/`](vision/) — research vision, problem space, and long-term roadmap.
- [`foundations/`](foundations/) — concise, durable notes on core concepts required by the research.
- [`research_tracks/`](research_tracks/) — concrete research questions, hypotheses, and study designs.
- [`ideas/`](ideas/) — exploratory ideas that have not yet become committed research tracks.
- [`landscape/`](landscape/) — prior work, industry signals, and novelty boundaries.
